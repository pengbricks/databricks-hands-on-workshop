# Lab 2: Genie: create and tune a Genie Agent

**Time:** 25 minutes

## Steps

1. Click **Genie Agents** in the sidebar, then **New**.
2. Choose `workspace.workshop.admissions_prepared` and `workspace.workshop.admissions_by_state`, then click **Create**. Read the table descriptions and example queries Genie Code proposes and accept the ones that are right.
3. Ask the three questions in `starter_questions.md`. Note which answers are wrong or vague.
4. Open **Configure**. Write an instruction that defines "selective" and says which year to use when the question names none.
5. Add one example query that lists the selective institutions in the latest year.
6. Ask the same three questions again and compare the answers.

## Done when

Question 3 gets the same answer every time you ask it.

## If stuck

Copy the instruction from `completed/lab2_genie_agent/instructions.txt` and the query from `completed/lab2_genie_agent/example_queries.sql`.

Docs: [Set up a Genie Agent](https://docs.databricks.com/aws/en/genie/set-up)
